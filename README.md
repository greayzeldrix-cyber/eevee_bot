# Galaxy Eevee Bot (React + Vite)

1. `npm install`
2. `npm start`  → baut die App und startet den Server
3. Dashboard: http://localhost:3001/   ·   OBS Browser-Quelle: http://localhost:3001/overlay (1920×1080)

Tipp: Das Dashboard lässt sich in OBS als „Benutzerdefiniertes Browser-Dock" (Docks → …) mit der Dashboard-URL einbinden.
Entwickeln mit Hot-Reload: `npm run dev` → http://localhost:5173/

Einstellungen liegen in `data/config.json` (enthält ggf. dein Bot-Token – nicht teilen!).
Der Server lauscht nur auf 127.0.0.1.
